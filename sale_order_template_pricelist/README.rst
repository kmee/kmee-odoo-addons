This Odoo module ensures that when a quotation template is selected on a
sale order, the pricelist defined in the template is automatically
applied to the order.

This behavior overrides the customer's default pricelist to enforce
consistent pricing based on the selected quotation template.

It is useful for campaigns like "Black Friday", where special templates
require specific pricelists regardless of customer configuration.

Configuration
=============

To configure this module, you need to:

1. Go to **Sales > Quotation Templates**
2. Edit or create a template
3. In the form view, set the **Pricelist** field
4. Save the template

When you select this template in a sale order, the order's pricelist
will automatically be updated to match the one defined in the template,
even if the customer has a different default pricelist.
