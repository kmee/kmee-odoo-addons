1. Go to *Purchase > Products > Products* and, in the *Purchase* tab of a
   product, fill in the manufacturer, the part number and the other manufacturer
   data.
2. Create a request for quotation and add the product. The manufacturer and
   the part number are shown in the line form and can be added to the line list
   with the optional columns selector.
3. Print the request for quotation or the purchase order. The report has the
   "Manufacturer/PartNumber" column.
