This module allows the validation of exceptions in a sale order. It uses
the mechanisms of the sale_tier_validation module to request that
reviewers ignore exceptions caught by the sale_exception module.

.. contents::
   :local:

Configuration
=============

To configure this module, you need to:

1. Go to *Settings > Technical > Tier Validations > Tier Definition*.

2. Edite o tier Sales Order Exceptions Approver, choosing the individual
   or group that will be able to ignore the exceptions.

3. Go to *Sales > Settings > Sale Exception Rules*.

4. Create as many exception rules as you need.

Usage
=====

Now every time a user tries to confirm a sale order containing an
exception defined by a rule, these exceptions are displayed on the
screen and the REQUEST VALIDATION button appears.
