SAC (Serviço de Atendimento ao Consumidor) is a customer service module for Odoo that helps manage customer inquiries, complaints and feedback.

Features:
* Track customer communications
* Manage product complaints
* Handle customer feedback
* Email integration
* Kanban view for case management

Usage
=====

To use this module, you need to:

1. Go to SAC > SAC
2. Create a new SAC record
3. Fill in customer information
4. Track the case through different stages
5. Communicate with customers via email
