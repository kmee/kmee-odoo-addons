Permite cadastrar produtos alternativos em cada linha da lista de materiais.
As alternativas são levadas para a linha de componente da ordem de produção e
para a separação de componentes (fabricação em 2 ou 3 passos), onde o
estoquista pode substituir o componente que falta por uma alternativa: a
separação e a ordem de produção passam a ter a linha do produto substituto e
a linha original é reduzida (ou cancelada, se toda a quantidade foi trocada).
