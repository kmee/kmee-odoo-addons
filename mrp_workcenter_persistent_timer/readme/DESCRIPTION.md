This module keeps the work order timer running when the operator leaves the tablet view.
By default, using the back button pauses the workcenter timer.

A second “back” button (arrow) is added on the work order tablet form: **Keep timer
running**. Using it navigates back without pausing the timer, so the workorder can keep
running in the background while the user does something else. The standard back button
(close icon) is hidden so the default action is to leave without pausing.
