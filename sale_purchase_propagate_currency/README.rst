This module automatically propagates the currency from a Sale Order to
its automatically created Purchase Orders in Make to Order (MTO)
scenarios.

.. contents::
   :local:

Configuration
=============

To use this module, you need to:

1. Configure products with the Make to Order (MTO) route
2. Ensure the Sale Purchase module is properly configured

Usage
=====

When using Make to Order products:

1. Create a sale order with a specific currency
2. Add products configured with MTO route
3. Confirm the sale order
4. The system will automatically create purchase orders with the same
   currency as the sale order
