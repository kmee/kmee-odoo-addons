This addon allows the propagation of the currency and pricelist from a
Purchase Order to a Sale Order in an intercompany flow.

**Table of contents**

.. contents::
   :local:

Configuration
=============

This addon doesn't require any configuration.

Usage
=====

When creating a Purchase Order for a partner that is another company in
the system, you can now select a pricelist. This pricelist and the
currency will be propagated to the generated Sale Order.
