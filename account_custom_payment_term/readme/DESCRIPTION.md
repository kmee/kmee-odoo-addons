This module enhances the management of payment terms for invoices by introducing manual
payment terms. Key features include:

- Associating manual payment lines with invoices, configurable with fixed dates,
  percentages, or remaining balance.
- Automatic updates to manual payment lines when invoice payment terms change, including
  creation, modification, and removal.
- Personalized calculation of invoice installments using defined manual terms,
  overriding Odoo's default behavior.

This customization ensures greater flexibility and control over invoice payment terms.
