This Odoo module defines personalized mappings for importing bank statements from different banks (Itaú, Santander, Sicredi and BTG) in XLS format, configuring how the data should be interpreted during import. For each bank, the relevant columns are specified, such as date, value, balance, description, and others, as well as settings to separate the fields correctly, ignore header or footer lines and format numbers (such as thousands and decimal separators). The objective is to standardize the process of importing bank statements from different sources, facilitating integration with the Odoo accounting system.
