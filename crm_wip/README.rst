This module extends Odoo's CRM functionality by adding Work in Progress
(WIP) features to opportunities. It allows tracking and managing
opportunities that are actively being worked on, helping sales teams
better organize their pipeline and prioritize their work.

Key features:

- WIP status tracking for opportunities
- Visual indicators for opportunities in progress
- Enhanced opportunity management workflow
- Integration with standard CRM features

Use Cases / Context
===================

This module was developed to address the need for better tracking of
active work on opportunities in the sales pipeline. It helps sales
teams:

- Identify which opportunities are currently being worked on
- Improve pipeline visibility and management
- Reduce overlap in sales team efforts
- Better organize and prioritize sales activities

Configuration
=============

To configure this module, you need to:

1. Go to Settings > Users & Companies > Users
2. Select the user(s) that should have access to WIP features
3. Under Access Rights tab, ensure they have proper CRM access rights
4. The WIP features will be automatically available in the CRM pipeline
   view

Usage
=====

To use this module:

1. Navigate to CRM > Pipeline
2. Select an opportunity
3. In the opportunity form, you'll find the WIP status field
4. Toggle the WIP status to indicate when you're actively working on the
   opportunity
5. Use the pipeline view to easily identify opportunities in progress

The WIP status helps track which opportunities are being actively worked
on, improving pipeline management and team coordination.
