L10n Br Payment Boleto Inter

Emite boletos de cobrança registrada pela API v3 do Banco Inter e acompanha o pagamento, como um provedor de pagamento (payment.provider) do Odoo.

O boleto é gerado a partir de uma transação de pagamento (fatura ou pedido de venda), com os dados do pagador, vencimento, desconto, multa e juros do modo de pagamento. O PDF fica guardado na transação e pode ser impresso pelo menu Imprimir da fatura e do pedido, ou aberto pelo portal com o token de acesso.

Um agendamento consulta o banco e confirma (ou cancela) a transação conforme a situação do boleto, o que dispara a conciliação do pagamento.

Use Cases / Context

Necessidade: a KMEE atende clientes que cobram por boleto no Banco Inter e precisam emitir, imprimir e conciliar os boletos sem sair do Odoo.

Abordagem: integração direta com a API v3 de cobrança do Inter (OAuth2 com certificado de cliente), sobre o módulo base l10n_br_payment_boleto, que já define o contrato dos provedores de boleto. É um caminho diferente da remessa CNAB (l10n_br_account_payment_order): aqui o registro e a baixa são online.

Relacionados: l10n_br_payment_boleto (base) e l10n_br_payment_boleto_pinbank (outro provedor, mesmo contrato).

Installation

O módulo usa a biblioteca requests, já presente em qualquer instalação do Odoo. O certificado de cliente do Inter é gravado em arquivos temporários durante cada chamada e removido em seguida.

Configuration

Em Faturamento > Configuração > Provedores de pagamento, abra o provedor Banco Inter e preencha (apenas usuários administradores veem estes campos):

  • Conta corrente;
  • Client ID e Client Secret da aplicação criada no Internet Banking do Inter (escopos de cobrança: leitura e escrita);
  • Certificado e chave privada (PEM) emitidos pelo Inter para a aplicação.

Use o estado Teste para o ambiente sandbox do Inter e Habilitado para produção. Depois, no modo de pagamento (Faturamento > Configuração > Modos de pagamento), aponte o provedor Inter e informe desconto, multa e juros.

Usage

  • Na fatura de cliente, com o modo de pagamento do Inter, ao confirmar a fatura (ou pelo botão de gerar boletos) é criada uma transação para cada vencimento em aberto e o boleto é registrado no Banco Inter. Gerar de novo não duplica boletos que já existem.
  • Imprima o boleto pelo menu Imprimir da fatura ou do pedido de venda; faturas parceladas saem com todos os boletos num só arquivo.
  • Para cancelar, use a ação de cancelar na transação: o boleto é cancelado no banco e a transação fica cancelada.
  • O agendamento Atualizar status de boletos Inter confirma a transação quando o boleto é pago.

Known issues / Roadmap

  • Receber a situação do boleto por webhook do Inter, com validação de assinatura, em vez de depender só do agendamento a cada 30 minutos.
  • Conferir o valor recebido (valorTotalRecebido) contra o valor da transação antes de confirmar o pagamento.
  • Avaliar se o boleto vencido deve mesmo cancelar a transação, já que o Inter aceita o pagamento até o fim do prazo de agenda.
