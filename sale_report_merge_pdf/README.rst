Configuration
=============

To configure this module, you need to:

1. Go to *Sales > Order > PDF Cover*.
2. In the "PDF Cover" section, add a PDF file to use it as a cover for
   the core sale order report.

Usage
=====

If you wish to print only the core sale order report, uncheck the 'Print
with Cover' option in the 'Other Info' tab of the sale order.
