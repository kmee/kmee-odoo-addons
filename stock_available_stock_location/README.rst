Acrescenta ao produto a quantidade "No estoque": o saldo apenas no local
de estoque dos armazéns (e em seus sublocais), sem os demais locais
internos do armazém (recebimento, expedição, produção, trânsito). O
botão do produto abre os saldos desses locais.

Usage
=====

1. Abra um produto armazenável: o botão *No estoque* mostra a quantidade
   apenas nos locais de estoque dos armazéns.
2. Clique no botão para ver os saldos desses locais. A coluna opcional
   *No estoque* também existe na lista de produtos.
