Este módulo acrescenta às linhas da lista de materiais (LdM) o campo
**Referência**, para registrar os designadores do componente na montagem
(por exemplo "R1, R2, C3"), e mostra na linha o fabricante, o nome e o
código do produto no fabricante, vindos do cadastro do produto.

Também impede salvar uma linha da LdM com quantidade zero.

Usage
=====

1. Cadastre, no produto, a aba/campos de fabricante (fabricante, nome e
   código do produto no fabricante).
2. Abra uma lista de materiais em *Manufatura > Produtos > Listas de
   materiais*.
3. Na aba *Componentes*, as colunas *Fabricante*, *Nome do produto no
   fabricante* e *Código do produto no fabricante* aparecem preenchidas
   a partir do produto da linha.
4. Preencha a coluna *Referência* com os designadores, separados por
   vírgula.
5. Informar quantidade zero em uma linha gera um erro de validação.
