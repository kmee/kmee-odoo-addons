Este módulo acrescenta às linhas da lista de materiais (LdM) o campo
**Referência**, para registrar os designadores do componente na montagem
(por exemplo "R1, R2, C3"), e mostra na linha o fabricante, o nome e o código
do produto no fabricante, vindos do cadastro do produto.

Também impede salvar uma linha da LdM com quantidade zero.
