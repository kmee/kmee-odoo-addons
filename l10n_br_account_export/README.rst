Envia lançamentos contábeis do Odoo para os sistemas usados pelos
escritórios de contabilidade brasileiros, eliminando a redigitação no
fechamento mensal.

Este módulo é o chassi: o lote de exportação, o controle do que já foi
enviado, a crítica antes de gerar e os utilitários de formatação de
arquivo. Os layouts de cada sistema ficam em módulos próprios.

- **Lote persistente**: período, diários e opções ficam gravados no
  registro, e não se perdem como aconteceria num assistente.
- **Um lançamento sai uma vez**: o vínculo é gravado no próprio
  ``account.move``, então desfazer a exportação é voltar o lote para
  rascunho.
- **Crítica antes do arquivo**: conta sem código no plano do escritório
  e lançamento desbalanceado são apontados antes de qualquer arquivo
  sair.
- **Reexportar é permitido**: o período pode receber uma segunda remessa
  (com aviso), porque lançamentos entram depois do primeiro envio.

Configuration
=============

1. Em *Faturamento / Configuração / Plano de Contas*, preencha o
   **Código no escritório** de cada conta. É o código reduzido do plano
   do escritório; sem ele, as partidas daquela conta são recusadas com
   crítica.
2. Em *Faturamento / Exportação Contábil / Configurações*, crie uma
   configuração escolhendo o **layout do destino** e a codificação
   (normalmente ANSI).

Usage
=====

Em *Faturamento / Exportação Contábil / Exportações*, crie um lote
informando o período e a configuração, clique em **Buscar lançamentos**
e depois em **Gerar arquivo**.

Os arquivos ficam anexados ao lote. Para refazer, use **Voltar para
rascunho**: isso apaga os arquivos e libera os lançamentos para uma nova
exportação.
