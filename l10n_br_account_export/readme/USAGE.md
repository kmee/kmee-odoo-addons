Em *Faturamento / Exportação Contábil / Exportações*, crie um lote informando o
período e a configuração, clique em **Buscar lançamentos** e depois em **Gerar
arquivo**.

Os arquivos ficam anexados ao lote. Para refazer, use **Voltar para rascunho**:
isso apaga os arquivos e libera os lançamentos para uma nova exportação.
