1. Em *Faturamento / Configuração / Plano de Contas*, preencha o **Código no
   escritório** de cada conta. É o código reduzido do plano do escritório; sem
   ele, as partidas daquela conta são recusadas com crítica.
2. Em *Faturamento / Exportação Contábil / Configurações*, crie uma configuração
   escolhendo o **layout do destino** e a codificação (normalmente ANSI).
