This module expands Odoo's recruitment functionality, allowing candidates to share and fill personalized forms online. When a candidate is registered in the system, a unique access token is generated, which is used to generate a link to a specific application form. This link is sent to the candidate by email, and the form can be filled out on the website portal. Through this form, the candidate can provide data such as banking information, ethnicity, dependents and other details, which are automatically registered in the Odoo system, associating them with the candidate. The Odoo interface has also been changed to include a button that makes it easier to send the form link to the candidate.
