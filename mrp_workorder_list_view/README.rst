This module makes work order views easier to use by changing the tablet
action (opened from the workcenter) to open in the current window
instead of fullscreen, and to show the list (tree) view first instead of
the kanban.

It also ensures the work order tree view has priority 0 so the editable
list is used when opening work orders.

.. IMPORTANT::
   This is an alpha version, the data model and design can change at any time without warning.
   Only for development or testing purpose, do not use in production.
   `More details on development status <https://odoo-community.org/page/development-status>`_
