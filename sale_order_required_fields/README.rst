Adiciona opções por empresa para tornar obrigatórios, no pedido de
venda, o modo de pagamento, o prazo de pagamento e a data de entrega de
cada linha. Os campos ficam obrigatórios no formulário e o pedido não é
confirmado sem eles, inclusive quando criado por importação ou por
código.

Configuration
=============

Em *Vendas > Configuração > Configurações*, na seção *Cotações e
pedidos*, ative as opções desejadas para a empresa:

- Exigir modo de pagamento
- Exigir prazo de pagamento
- Exigir data de entrega na linha

Usage
=====

Crie uma cotação. Com as opções ativas, o modo de pagamento, o prazo de
pagamento e a data de entrega de cada linha de produto aparecem como
obrigatórios. Confirmar um pedido sem algum deles mostra um erro
listando o que falta.
