The goal of this document is to explain quickly the features of this module: “what” this module does and “what” it is for. ]

This module adds advanced functionality for managing vacation allocation plans in Odoo. It allows for the automatic creation of new allocations based on predefined plans, ensuring that a newly hired employee has their accrual plans set up automatically.
