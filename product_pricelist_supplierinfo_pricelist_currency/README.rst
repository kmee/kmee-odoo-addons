This module extends the functionality of product pricelists to allow
filtering supplier information based on the pricelist currency.

**Table of contents**

.. contents::
   :local:

Configuration
=============

To use this module, you must first define pricelists that behave as
Filter by Pricelist Currency. This option is only available for
supplierinfo based pricelists.

Usage
=====

To use this module, you need to:

1. Go to Sales > Products > Pricelists
2. Create or edit a pricelist with Filter by Pricelist Currency checked
3. The system will now filter supplier information to match the
   pricelist currency
