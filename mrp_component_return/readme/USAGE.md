Na base de demonstração, o armazém *Fábrica Serra Azul* tem uma ordem de
produção de duas mesas com os componentes já separados e só os tampos
consumidos.

1. Abra *Manufatura > Relatórios > OPs: Reservas Pendentes* e clique em
   **Resolver reservas** na ordem de produção. O assistente de devolução da
   separação oferece apenas o que não foi consumido.
2. Alternativamente, abra a ordem de produção e clique em **Devolver tudo**.
   A devolução é criada em pré-produção para estoque; valide-a.
3. Tente cancelar ou concluir a ordem antes de devolver: o sistema orienta a
   usar **Devolver tudo**.
