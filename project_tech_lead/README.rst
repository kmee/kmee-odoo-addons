Creates the Tech Lead field for tasks and projects.

**Table of contents**

.. contents::
   :local:

Usage
=====

In a task form you can assign a tech lead in the **Tech Lead** field.
And in the kanban view of a project you can click on *Group By > Tech
Lead* and you will see the tasks separated by tech lead.
