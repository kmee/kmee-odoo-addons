Cria acordos de compra (`purchase.requisition`) a partir de uma ordem de produção, pelos componentes que ainda não estão reservados.

- Botão *Acordo de Compra* na ordem de produção, com assistente de quantidades faltantes, data futura e justificativa.
- Um segundo acordo para a mesma ordem exige justificativa.
- A ordem de produção mostra os botões de demandas, acordos, compras e recebimentos ligados a ela.
- As linhas do acordo guardam a ordem de produção, a data agendada, a justificativa, o código interno e o código do fabricante; o acordo e o pedido de compra listam as ordens de origem.
