Cria acordos de compra (``purchase.requisition``) a partir de uma ordem
de produção, pelos componentes que ainda não estão reservados.

- Botão *Acordo de Compra* na ordem de produção, com assistente de
  quantidades faltantes, data futura e justificativa.
- Um segundo acordo para a mesma ordem exige justificativa.
- A ordem de produção mostra os botões de demandas, acordos, compras e
  recebimentos ligados a ela.
- As linhas do acordo guardam a ordem de produção, a data agendada, a
  justificativa, o código interno e o código do fabricante; o acordo e o
  pedido de compra listam as ordens de origem.

Usage
=====

1. Em *Fabricação*, abra uma ordem de produção confirmada.
2. Clique em *Acordo de Compra*. O assistente lista os componentes que
   faltam reservar, com a quantidade sugerida.
3. Ajuste as quantidades, informe a data futura e, se a ordem já tem um
   acordo, a justificativa.
4. Clique em *Criar*. O acordo de compra é aberto e a ordem de produção
   passa a mostrar os botões *Demandas*, *Acordos*, *Compras* e
   *Recebimentos*.
5. Em *Compras > Pedidos > Linhas do Acordo de Compra* veja as demandas
   de todas as ordens.
