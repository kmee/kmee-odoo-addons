No diário de compras, use o botão de upload de fatura (ou o menu Fiscal >
Importar Documento) e envie o PDF ou a imagem. O assistente abre com os
dados extraídos (fornecedor localizado pelo CNPJ, número, datas, valores,
ISS e retenções) para conferência. Ajuste o que precisar e confirme: o
documento fiscal de serviço (e a fatura, conforme a configuração) é criado
com o arquivo original anexado.

Se a configuração for "somente Documento Fiscal", a fatura pode ser criada
depois: abra uma fatura de fornecedor em rascunho, aponte o campo Documento
Fiscal para o documento importado e use "Importar documento fiscal".
