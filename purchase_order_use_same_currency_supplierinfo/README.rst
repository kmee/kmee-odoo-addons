This module enforces currency consistency in purchase orders by
filtering supplier information lines to match the currency of the
purchase order.

**Table of contents**

.. contents::
   :local:

Configuration
=============

This addon doesn't require any configuration.

Usage
=====

When creating or editing a purchase order:

1. Select a currency for the purchase order
2. The system will automatically filter supplier information to show
   only prices in the selected currency
3. This ensures consistency between the purchase order currency and
   supplier prices
