1. Create one group per team in *Settings > Users & Companies > Groups*
   (for instance *Billing team* and *Treasury team*) and add the users.
2. In *Invoicing > Configuration > Journals*, open a journal, go to the
   **Advanced Settings** tab and fill **Allowed Groups** in the
   **Access by Group** section. The field is visible to accounting
   administrators.

Before restricting a journal, add to it a group that the administrators
belong to: an administrator outside the allowed groups no longer sees the
journal, including in the configuration menu.
