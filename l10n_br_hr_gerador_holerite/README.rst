Wizard para geração em lote de holerites (folhas de pagamento) para
simulação de um ciclo anual completo.

A partir de um contrato e um mês/ano inicial, gera 12 holerites mensais
consecutivos, calculando automaticamente cada um.

Útil para simulações de férias, 13º salário e projeções salariais.
