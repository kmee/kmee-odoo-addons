This module allows disabling ir_cron runs via env vars.
Useful for updating large databases where lock errors occur.

e.g. DISABLE_CRON_DURING_UPDATE=1 in env file

**Table of contents**

.. contents::
   :local:

Usage
=====

To use this module, you need to set the env var during update:

DISABLE_CRON_DURING_UPDATE=1 in env file
