Configuration
=============

To configure this module, you need to:

1. Go to *Project > Configuration > Service Class*, create the classes.

Usage
=====

In a task form you can assign a class in the Service Class field. And in
the kanban view of a project you can click on *Group By > Service Class*
and you will see the tasks separated by class.
