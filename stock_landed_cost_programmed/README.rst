Adds a programmed pickings field to stock.landed.cost and a button to
copy ready pickings to picking_ids.

.. contents::
   :local:

Configuration
=============

This addon doesn't require any configuration.

Usage
=====

Go to a landed cost and register the required programmed pickings to it.
Once all the programmed pickings are done, a button will be displayed
allowing the automatic transfer of programmed pickings to the original
LC field picking_ids.
