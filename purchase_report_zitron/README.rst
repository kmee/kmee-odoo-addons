Zitron layout for the purchase order PDF (also used for requests for
quotation): company and fiscal block on the first page, side-by-side
billing and delivery addresses, buyer contact, payment term, project,
and a line table with cost center and unit columns, printed in portrait.

Configuration
=============

The report paper format is installed by the module. The fixed note
printed at the end of the last page is edited in the company form, tab
Purchase Report.

Usage
=====

To use this module, you need to:

1. Open a purchase order or request for quotation.
2. Print it with the Zitron layout from the Print menu.
