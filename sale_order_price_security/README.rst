This module creates a group in which only those in this group can edit
the sales price in a sale order.

Use Cases / Context
===================

In some flows in certain companies, some employees cannot change the
selling price of a product in a sale order.

Configuration
=============

To configure this module, you need to:

1. Go to *Settings > Users & Companies > Users*.
2. In a user that you would like to be able to edit the sale price in
   sale order, in the **Access Rights** tab click on **Can Edit The
   Price in Sale**.

Usage
=====

To use this module, you need to:

1. Go to *Sales > Orders > Quotation*.
2. Within a sales order, only users who belong to the **Can Edit The
   Price in Sale** group can edit the **Unit Price** field.
