#. Marque "Purchase Request" no produto comprado que tem buffer DDMRP.
#. No buffer, use "Procure": o sistema cria a requisição de compra em rascunho.
#. O buffer passa a mostrar a quantidade em "Requested" e a recomendação de
   reposição cai pela quantidade requisitada.
#. Quando a requisição vira cotação, a quantidade sai de "Requested" e passa a
   ser contada nas cotações em andamento, uma vez só. Requisição rejeitada
   devolve a quantidade à recomendação.
