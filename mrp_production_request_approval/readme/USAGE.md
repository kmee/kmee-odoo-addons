1. Em *Fabricação > Pedidos de produção*, abra um pedido e preencha os *Aprovadores* (usuários do grupo de gestores de pedidos de produção).
2. O pedido segue para aprovação pelo botão *Solicitar aprovação*. Um aprovador usa *Aprovar*; o pedido passa a mostrar quem aprovou e quando.
3. Se o pedido foi concluído por engano, um aprovador usa *Reabrir* para voltar ao estado *Aprovado*.
