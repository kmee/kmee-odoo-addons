Acrescenta ao pedido de produção (`mrp_production_request`) uma lista de aprovadores, o registro de quem aprovou e quando, e a opção de reabrir um pedido concluído, restrita aos aprovadores.

- Só os aprovadores indicados no pedido podem aprová-lo ou reabri-lo. Sem aprovadores, qualquer gestor de pedidos de produção pode.
- Ao aprovar, o pedido registra *Aprovado por* e *Aprovado em*.
- Um pedido concluído por engano, com produção parcial, volta para *Aprovado* pelo botão *Reabrir*.
