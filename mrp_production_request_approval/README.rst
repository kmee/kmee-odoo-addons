Acrescenta ao pedido de produção (``mrp_production_request``) uma lista
de aprovadores, o registro de quem aprovou e quando, e a opção de
reabrir um pedido concluído, restrita aos aprovadores.

- Só os aprovadores indicados no pedido podem aprová-lo ou reabri-lo.
  Sem aprovadores, qualquer gestor de pedidos de produção pode.
- Ao aprovar, o pedido registra *Aprovado por* e *Aprovado em*.
- Um pedido concluído por engano, com produção parcial, volta para
  *Aprovado* pelo botão *Reabrir*.

Usage
=====

1. Em *Fabricação > Pedidos de produção*, abra um pedido e preencha os
   *Aprovadores* (usuários do grupo de gestores de pedidos de produção).
2. O pedido segue para aprovação pelo botão *Solicitar aprovação*. Um
   aprovador usa *Aprovar*; o pedido passa a mostrar quem aprovou e
   quando.
3. Se o pedido foi concluído por engano, um aprovador usa *Reabrir* para
   voltar ao estado *Aprovado*.
